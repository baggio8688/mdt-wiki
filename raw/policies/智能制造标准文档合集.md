## 一、GB/T 正式国标（已发布）

### 1. GB/T 39116-2020 智能制造能力成熟度模型

| 项目 | 内容 |
|------|------|
| **标准编号** | GB/T 39116-2020 |
| **中文名称** | 智能制造 能力成熟度模型 |
| **英文名称** | Intelligent manufacturing — Capability maturity model |
| **发布日期** | 2020-10-11 |
| **实施日期** | 2021-05-01 |
| **归口单位** | 工业和信息化部（电子工业标准化研究院） |
| **定位** | 定义智能制造能力成熟度的**模型框架**、等级划分和评估维度 |

> 📄 [下载 PDF](assets/gbt-39116-2020-智能制造能力成熟度模型.pdf)

**主要结构：**
- 成熟度等级：一级（规划级）→ 二级（规范级）→ 三级（集成级）→ 四级（优化级）→ 五级（引领级）
- 评估维度：人员、技术、资源、制造（设计/生产/物流/销售/服务）
- 能力域：每个维度下细分若干能力子域

### 2. GB/T 39117-2020 智能制造能力成熟度评估方法

| 项目 | 内容 |
|------|------|
| **标准编号** | GB/T 39117-2020 |
| **中文名称** | 智能制造 能力成熟度评估方法 |
| **英文名称** | Intelligent manufacturing — Capability maturity assessment method |
| **发布日期** | 2020-10-11 |
| **实施日期** | 2021-05-01 |
| **定位** | 对 GB/T 39116 模型的**配套评估方法**，规定评估流程、评分规则和等级判定 |

> 📄 [下载 PDF](assets/gbt-39117-2020-智能制造能力成熟度评估方法.pdf)

**主要结构：**
- 评估原则：客观性、系统性、可操作性
- 评估流程：启动 → 自评估 → 现场评估 → 等级判定 → 报告
- 评分规则：每个能力子域的评分细则
- 等级判定矩阵
