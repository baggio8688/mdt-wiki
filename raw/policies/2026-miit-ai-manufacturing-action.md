# 八部门《"人工智能+制造"专项行动实施意见》

> **发文字号：** 工信部联科〔2025〕279号
> **成文日期：** 2025-12-25
> **发布日期：** 2026-01-07
> **发布机构：** 工业和信息化部、中央网信办、国家发展改革委、教育部、商务部、国务院国资委、市场监管总局、国家数据局

---

## 📋 一、制定背景与总体要求

人工智能加速与实体经济深度融合，深刻改变制造业生产模式和经济形态，成为驱动产业升级、重塑全球格局的关键变量。为贯彻落实《关于深入实施"人工智能+"行动的意见》，加快推进人工智能技术在制造业融合应用，打造新质生产力，全方位、深层次、高水平赋能新型工业化，制定本实施意见。

**指导思想：** 坚持创新驱动、场景牵引、市场主导、安全可信、开放共享、普惠融通，一端抓技术供给（"智能产业化"），一端抓赋能应用（"产业智能化"），促进人工智能科技创新与产业创新深度融合、人工智能技术与制造业应用"双向赋能"。

## 🎯 二、核心目标（到2027年）

| 指标 | 目标值 |
|:----|:------:|
| 通用大模型在制造业深度应用 | 3～5个 |
| 高水平工业智能体 | 1,000个 |
| 工业领域高质量数据集 | 100个 |
| 典型应用场景推广 | 500个 |
| 标杆企业选树 | 1,000家 |
| 全球影响力生态主导型企业 | 2～3家 |
| 专精特新中小企业 | 一批 |

## 📂 三、七大重点任务

### （一）创新筑基：夯实人工智能赋能底座

**1. 强化人工智能算力供给**
- 突破高端训练芯片、端侧推理芯片、AI服务器、高速互联、智算云操作系统等关键技术
- 加快建设全国一体化算力网监测调度平台
- 开展智算云服务试点，推动大模型一体机、边缘计算服务器、工业云算力部署

**2. 开发高水平行业模型**
- 培育重点行业大模型，发展"云－边－端"模型体系
- 打造面向工业细分场景小模型，鼓励大小模型协同创新
- 推动模型轻量化部署，建设大模型评测基准体系

**3. 开展"模数共振"行动**
- 建立企业首席数据官制度，推进数据管理能力成熟度国家标准贯标
- 发布制造业高质量数据集建设指南
- 建立"数据协同、模型训练、应用开发、安全保障"一体化机制

### （二）赋智升级：拓展推广高价值应用场景

**4. 加快重点行业应用赋能**
- 深入开展AI赋能新型工业化"深度行"活动
- 分类制定"人工智能+制造"行业应用全景图和转型路线图
- 重点赋能：**原材料、装备制造、消费品、电子信息、软件和信息技术服务**等制造业重点行业

**5. 加速全流程转型升级**

| 环节 | 重点方向 |
|:----|:--------|
| **研发设计** | 智能辅助设计、软件代码辅助编写、药物研发 |
| **中试验证** | 虚拟仿真、多模态融合、工艺优化 |
| **生产制造** | 工业核心流程控制、机器视觉质检、无人智能巡检、设备预测性维护 |
| **营销服务** | 智能客服、数字人、个性化推荐、服务化延伸 |
| **运营管理** | 订单处理、销量预测、库存预警、供应链管理、战略/人力/财务/风险管理 |

**6. 提升重点企业应用水平**
- 开展制造业企业智能化成熟度评估
- 实施《制造业企业人工智能应用指南》（附件2）
- 鼓励龙头企业、央国企先行先试
- 支持中小企业开展数字化、智能化改造

**7. 推进重点区域推广应用**
- 依托国家自主创新示范区、国家高新区、国家级经开区
- 支持先进制造业集群、数字产业集群

**8. 推动重点领域智能化升级**
- AI与工业互联网平台融合赋能
- AI赋能绿色制造（能源和碳排放管理、资源循环利用）
- 工业安全领域AI应用（安全大模型、智能体）

### （三）产品突破：构建智能新产品新业态

**9. 推动智能装备迭代**
- 工业母机、工业机器人搭载智能体
- 新一代AI数控系统
- 手术机器人、智能诊断系统
- 大飞机、船舶重大技术装备AI融合
- 智能网联汽车、无人机等智能低空装备

**10. 加速智能终端升级**
- 智能手机、电脑、平板、智能家居AI终端
- AR/VR可穿戴设备、脑机接口
- 具身智能、人形机器人中试基地和标杆产线

**11. 打造智能体新业态**
- 工业智能体任务规划、群体协同
- 智能体开放协议和接口标准
- 智能体应用商店建设运营
- 智能体分类分级管理体系

### （四）主体培育：打造人工智能发展和赋能应用主力军

**12. 梯次培育企业**
- 全球影响力生态主导型企业
- 专精特新"小巨人"、高新技术企业、制造业单项冠军、独角兽和瞪羚企业
- 鼓励"算力券""模型券"等政策支持

**13. 打造创新载体**
- AI领域国家制造业创新中心
- 重点实验室（类脑智能、世界模型等前沿技术）
- 国家AI应用中试基地

**14. 发展赋能应用服务商**
- AI赋能应用加速器
- 生态伙伴型服务商
- 电信运营商和央国企数智科技公司赋能服务

### （五）生态壮大：加强资源配置优化产业生态

**15. 强化标准引领**
- 工信部AI标委会、全国数据标准化委员会等标准组织协同
- 基础标准（安全、治理、伦理）+ 通用标准（软硬协同）+ 赋能应用标准
- 鼓励企业参与国际标准化工作

**16. 推动开源开放**
- 高水平AI开源社区
- 模型、数据集、智能体等优质开源项目
- 开发者大会、"校源行"等活动

**17. 加强人才引育**
- AI产业人才需求预测报告
- 北京中关村学院、上海创智学院、深圳河套学院等
- 复合型人才培养（既懂AI又懂制造业）
- 科技领军人才和创新团队

### （六）安全护航：筑牢应用赋能安全保障

**18. 提升安全保障能力**
- 深度合成鉴伪、工业模型算法安全防护、训练数据保护
- 安全风险库、语料库，工业安全大模型
- 增强AI透明度、可解释性，降低幻觉风险

**19. 建立安全治理机制**
- AI分类分级、评估评测、应急处置等安全政策标准
- 柔性治理机制
- AI安全风险监测预警技术体系

### （七）加强组织保障

**20. 建立工作机制**
- 各部门协同推进，地方工信主管部门牵头落实
- 定期评估和动态调整工作机制

**21. 强化政策支持**
- 统筹利用现有资金渠道
- 国家产融合作平台对接
- 引导社会资本投入

**22. 营造良好环境**
- 宣传推广典型案例和成功经验
- 组织AI赋能新型工业化现场会
- 营造良好的产学研用协同创新氛围

## 📎 附件结构

### 附件1：人工智能赋能制造业重点行业转型指引

覆盖 **4大行业类型**：

| 行业 | 转型方向 |
|:----|:--------|
| **原材料行业**（钢铁、石化化工、有色金属、建材） | 工艺优化、能耗管理、安全生产、质量检测 |
| **装备制造行业**（工业母机、汽车、医疗装备、电力装备、船舶、航空航天） | 智能设计、预测性维护、柔性生产、供应链协同 |
| **消费品行业**（轻工、纺织、食品、医药、家居） | 个性化定制、智能客服、质量追溯、需求预测 |
| **电子信息行业**（电子元器件、消费电子、新型显示、软件、信息通信） | 智能排产、良率提升、自动化测试、代码辅助开发 |

### 附件2：制造业企业人工智能应用指南

**9大步骤**引导企业系统化推进AI应用：

| 阶段 | 步骤 | 关键内容 |
|:----|:---:|:--------|
| 一、评估规划 | 1～3 | 明确应用目标、梳理分析业务场景、制定实施方案 |
| 二、基础准备 | 4～5 | 数据资源准备、模型底座选型与准备 |
| 三、模型调优 | 6～7 | 提示词工程与检索增强调优、模型微调适配典型场景 |
| 四、部署集成 | 8～9 | 部署与集成、模型性能验证与易用性提升 |
| 五、持续优化 | 10～14 | 评估应用成效、迭代优化升级、深化技术融合、输出优秀方案 |
| 六、安全保障 | 15～17 | 数据安全防护、应用安全风险防范、网络安全防护水平提升 |
| 七、组织保障 | 18～19 | 压实主体责任、加强复合人才培养、参与生态共建 |

## 📝 关键亮点总结

1. **八部门联合发文** — 工信部牵头，网信办、发改委、教育部、商务部、国资委、市场监管总局、国家数据局联合，展示跨部门协同机制
2. **"模数共振"写入正文** — 第（三）条明确开展"模数共振"行动，已作为独立文件正式发文（2026年4月）
3. **智能工厂梯度培育对接** — 第（五）条明确"深化智能工厂梯度培育"，与本实施意见直接联动
4. **全流程覆盖** — 从研发设计到运营管理5大环节全覆盖
5. **新业态前瞻布局** — 具身智能、人形机器人、脑机接口、工业智能体等写入政策
6. **安全治理并重** — 专设"安全护航"章节，强调数据安全、模型安全、供应链安全
