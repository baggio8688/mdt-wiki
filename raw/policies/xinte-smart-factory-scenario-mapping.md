# 新特能源卓越级智能工厂申报：要素条件逐项对标与数字化场景方案

> **编制说明：** 依据《六部门关于开展2025年度智能工厂梯度培育行动的通知》（工信厅联通装函〔2025〕251号）附件《智能工厂梯度培育要素条件（2025年版）》"卓越级"要求，对5大环节、全部要素条件逐项分析，整合为**25个数字化场景**。覆盖卓越级"原则上覆盖全部5环节"要求，五大类无一缺项。亮点场景标注⭐。

---

## 一、工厂建设（工厂建设+信息基础设施环节）

**卓越级要求：** 工厂级数字化规划+数据治理，系统建模和优化，数字化交付，虚拟工厂

### ⭐ S1 工厂级数字化顶层规划与系统建模
| 维度 | 内容 |
|------|------|
| **对应场景** | 工厂建设-场景1：产线级/车间级/工厂级数字化规划与设计 |
| **现有基础** | 新特能源已构建完整的数字化战略架构，由中控技术、和利时等头部企业提供整体解决方案。甘泉堡工厂以DCS+APC+MES+EMS为骨架的数字化体系已运行多年；准东五彩湾20万吨项目采用和利时OCS工业光总线控制系统一体化方案（OCS+SIS+GDS+OTS+APC），以"标准化工程替代定制化工程"理念设计，从规划阶段即实现系统级架构设计。 |
| **卓越级对标** | ✅ **满足。** 已实现工厂级数字化规划，涵盖人员、物料、设备、能源、工艺各要素的系统级规划与布局仿真。准东项目采用OCS光总线技术大幅减少机柜间面积、节省投资、缩短项目周期，体现工厂级系统优化能力。 |
| **佐证材料** | 和利时合同、中控DCS+APC整体方案、工厂数字化顶层设计文档、OCS系统架构图 |
| **差异/Gap** | 需完善正式的《智能制造发展规划》文件，明确未来3-5年数字化演进路线图 |

### S2 数字基础设施建设
| 维度 | 内容 |
|------|------|
| **对应场景** | 工厂建设-场景2（基础建设）+ 信息基础设施-场景34-36（工业网络/数据采集/计算存储） |
| **现有基础** | 全厂部署50+ DCS控制站点、13,500+仪表点位。工业以太网覆盖全厂生产区域，SCADA系统实现全流程数据实时采集。甘泉堡工厂已部署中控DCS、SIS、MES、EMS、报警管理、可燃气体报警等多套系统。准东新项目采用OCS工业光总线控制系统，实现从公用工程到精馏、冷氢化、还原炉等主装置控制一体化。 |
| **卓越级对标** | ✅ **满足。** 具备完善的工业网络、数据采集体系和边缘侧计算能力。OCS光总线技术代表了新一代控制架构，带宽和实时性指标优于传统DCS。 |
| **佐证材料** | DCS/SIS系统拓扑图、仪表台账清单、网络架构图、OCS系统说明书 |
| **差异/Gap** | 可考虑补充5G专网（多晶硅行业已有成功案例，如通威5G+全连接工厂），作为加分项 |

### ⭐ S3 数据治理体系
| 维度 | 内容 |
|------|------|
| **对应场景** | 工厂建设-场景4：数据治理+场景5：工业技术软件化 |
| **现有基础** | 新特能源通过中控MES及厂级实时数据中心（HiaPlantODS等）实现全厂生产数据的统一采集、存储和管理。生产过程数据（温度、压力、流量、液位、组分等数万点）经过质量校验后进入MES/EMS系统，形成可靠的基础数据资产。 |
| **卓越级对标** | ✅ **满足。** 已建立涵盖生产、质量、能源、设备的多源数据采集与治理体系。数据质量管理、数据资产分类已初步形成。准东项目规划数据治理更完善。 |
| **佐证材料** | MES系统数据字典、数据质量管理制度、数据资产目录、实时数据库架构 |
| **差异/Gap** | 建议补充正式的数据治理标准文件（数据标准、元数据管理规范），可参考GB/T 36073-2018数据管理能力成熟度模型 |

### S4 虚拟工厂与数字化交付
| 维度 | 内容 |
|------|------|
| **对应场景** | 工厂建设-场景3：数字孪生工厂 |
| **现有基础** | 甘泉堡工厂已完成8代多晶硅技术迭代升级，积累了完整的工艺设计数据包（BEDP），涵盖精馏、还原、冷氢化等主装置的三维模型和工艺参数。准东20万吨项目采用OTS仿真系统（Hollysys HiaSim），可实现操作员培训、工艺方案验证和"开车前"虚拟演练。中控APC项目中已建立了25座精馏粗分塔+6座精馏塔+3台流化床等先进控制模型。 |
| **卓越级对标** | ✅ **基本满足。** 具备工艺仿真能力和OTS系统，操作站可以模拟还原炉、精馏塔等场景。但需要进一步整合为**全厂级数字孪生平台**，实现物理工厂与虚拟工厂的实时数据同步。 |
| **佐证材料** | OTS仿真系统建设方案、APC控制模型清单、三维设计模型文件、工艺包文件 |
| **差异/Gap** | 建议在甘泉堡或准东项目中引入数字孪生平台（如AVEVA、Hollysys HiaVR三维数字孪生），实现"虚实映射+预测推演"功能 |

### S5 工业技术软件化（工艺知识沉淀）
| 维度 | 内容 |
|------|------|
| **对应场景** | 工厂建设-场景5：工业技术软件化 |
| **现有基础** | 经过8代技术迭代，新特能源在还原炉热场控制、精馏提纯参数优化、还原沉积工艺等方面沉淀了大量工艺知识。APC控制器中的数学模型、OTS仿真中的工艺流程模型、以及MES中的工艺参数配方表，本质上是工艺知识的软件化表达。 |
| **卓越级对标** | ✅ **基本满足。** 已有工艺参数配方管理、APC控制模型等知识软件化成果。建议进一步建设**工艺知识图谱**或**专家系统**，实现隐性知识的显性化和系统化复用。 |
| **佐证材料** | APC控制器模型文档、工艺参数配方清单、OTS仿真工艺模型清单 |
| **差异/Gap** | 建议补充知识管理系统或工艺知识库平台，将多晶硅生产know-how从"人脑经验"升级为"系统知识资产" |

> **工厂建设合计：5个场景 ✅ 全部覆盖**

## 二、研发设计（产品设计+工艺设计环节）

**卓越级要求：** 协同研发设计、集成建模和仿真，基于模型和数据的系统优化

### ⭐ S6 产品数字化研发设计
| 维度 | 内容 |
|------|------|
| **对应场景** | 研发设计-场景6：产品数字化设计 |
| **现有基础** | 新特能源从2016年国家首批光伏行业智能制造试点示范至今，已完成八代多晶硅生产技术迭代升级。产品研发过程已实现数字化支撑，涵盖产品纯度等级设计、杂质控制模型、N型硅料/电子级多晶硅等高端产品的研发路径数字化。 |
| **卓越级对标** | ✅ **基本满足。** 产品研发设计已数字化，但需进一步建设**PLM（产品生命周期管理）平台**，实现从产品概念设计→工艺设计→试产→量产的全数字化闭环管理。 |
| **佐证材料** | 各代际产品技术资料、硅料纯度标准文件、产品设计文档 |
| **差异/Gap** | 建议引入PLM系统（如达索3DE、西门子Teamcenter、思普等），建立产品数据管理的统一平台 |

### S7 工艺仿真与集成建模
| 维度 | 内容 |
|------|------|
| **对应场景** | 研发设计-场景7：虚拟仿真与验证 + 场景12/13：系统建模与仿真优化 |
| **现有基础** | 中控APC项目中已建立了覆盖原料工序25座精馏粗分塔、冷氢化工序6座精馏塔和3台流化床的先进控制模型。OTS仿真系统可模拟从公用工程到主装置的完整工艺过程。精馏塔APC控制优化学术论文（《化工自动化及仪表》2024年发表）证明了工艺建模、控制仿真与优化的深度。和利时提供的HiaSim工艺流程模拟系统支持动态仿真验证。 |
| **卓越级对标** | ✅ **满足。** 已实现覆盖精馏、冷氢化、还原等核心工艺的集成建模与仿真优化。APC控制器中的多变量预测模型就是"基于模型和数据的系统优化"的典型体现。 |
| **佐证材料** | APC控制模型设计文档、OTS仿真方案、学术论文全文（《多晶硅精馏塔的基础控制优化及APC控制器应用》） |
| **差异/Gap** | 无重大差距。可考虑开展CFD流体仿真优化还原炉流场 |

### ⭐ S8 协同研发设计（产学研）
| 维度 | 内容 |
|------|------|
| **对应场景** | 研发设计-场景8：协同研发设计 |
| **现有基础** | 新特能源与中科院、清华大学、天津大学、浙大中控、和利时等形成了产学研协同创新体系。中控APC团队与现场技术团队联合优化200多个PID回路和中控APC模型，是典型的研发协同案例。2018年"高纯晶体硅材料智能制造关键技术开发与应用项目"获新疆科技进步一等奖，属产学研协同成果。 |
| **卓越级对标** | ✅ **满足。** 跨部门、跨企业协同研发已成熟。建议进一步建设信息化协同研发平台，实现研发数据和成果的在线共享与协同。 |
| **佐证材料** | 产学研合作协议、获奖证书、联合发表论文清单、专利清单 |
| **差异/Gap** | 可考虑部署协同研发数字化平台（如达索3DE xCAD协同）提升效率 |

### S9 知识驱动的创新研发
| 维度 | 内容 |
|------|------|
| **对应场景** | 研发设计-场景9：知识驱动研发 |
| **现有基础** | 新特能源8代多晶硅技术迭代积累了大量工艺优化经验数据。APC系统的模型和精馏塔优化论文案例展示了以数据驱动方法优化工艺参数的路径。中控技术的TPT（时间序列大模型）等AI技术可赋能过程优化和研发创新。2024年"工业互联网+大数据硅基新材料制造试点示范项目"入选新疆工业互联网优秀案例，体现了大数据驱动的研发能力。 |
| **卓越级对标** | ✅ **基本满足。** 已有数据驱动工艺优化的初步实践。建议引入AI辅助研发工具（如材料基因组、工艺参数推荐系统），加速电子级多晶硅等高附加值产品的研发。 |
| **佐证材料** | 大数据项目方案、APC优化数据报告 |
| **差异/Gap** | 建议在准东项目中引入AI辅助研发试点，将历史生产数据用于新工艺参数的智能推荐 |

> **研发设计合计：4个场景 ✅ 全部覆盖**

## 三、生产作业（生产作业+质量管控+设备管理环节）

**卓越级要求：** 设备智能分析诊断、生产过程智能管控和在线优化、过程质量在线检测控制

### ⭐ S10 先进过程控制APC（核心亮点）
| 维度 | 内容 |
|------|------|
| **对应场景** | 生产作业-场景12：先进过程控制 |
| **现有基础** | **这是新特能源最突出的亮点之一。** 2019年中控承建的36000吨/年高纯多晶硅装置APC与PID项目成功验收：
- 覆盖原料工序25座精馏粗分塔、冷氢化工序6座精馏塔、3台流化床
- 完成了200多个重点PID控制回路的参数整定与优化
- 实现全厂PID控制回路实时监控和性能评估
- PID自控率**98%以上**、性能优良率**80%以上**
- 各工序关键工艺参数波动幅度降低**30%以上**
- 平稳率达到**95%以上**
- 学术论文发表于《化工自动化及仪表》（核心期刊），证明了行业领先的技术深度
准东新项目同样包含APC先进控制系统。 |
| **卓越级对标** | ✅ **充分满足，属优势项。** APC覆盖精馏、冷氢化、流化床等核心工序，控制模型覆盖全流程，自控率和性能指标优秀，是"生产过程智能管控和在线优化"的典型体现。 |
| **佐证材料** | APC项目验收报告、PID回路性能评估报告、波动降低统计图表、中控验收新闻、学术论文 |
| **差异/Gap** | 还原炉APC（精馏已覆盖，还原炉是中控一体化方案的一部分）——需确认还原炉是否已实施APC或仅为基础控制 |

### ⭐ S11 智能生产作业（自动化产线）
| 维度 | 内容 |
|------|------|
| **对应场景** | 生产作业-场景11：智能生产作业 |
| **现有基础** | 还原车间、合成车间实现DCS集中监控。核心工序自动化水平高：
- 全厂50+ DCS站点、13,500+检测控制点位
- 自动化破碎、清洗、包装产线（后处理工序）
- 精馏工序实现APC全自动运行（平稳率95%）
- 冷氢化、流化床等工序DCS自动控制
- OCS工业光总线控制系统（准东新项目），标准化程度更高 |
| **卓越级对标** | ✅ **满足。** 多晶硅生产典型流程（还原→破碎→清洗→包装）已实现较高程度的自动化。后处理环节自动化水平可进一步核实。 |
| **佐证材料** | 自动化产线清单、DCS控制策略文档、自动化率统计报表 |
| **差异/Gap** | 建议统计关键工序数控化率；若后处理自动化比例低于90%，可列为自动化升级计划 |

### S12 设备智能分析诊断
| 维度 | 内容 |
|------|------|
| **对应场景** | 设备管理-场景17：设备智能维护 |
| **现有基础** | DCS系统已具备设备运行状态实时监控、异常报警和故障诊断功能。关键设备（还原炉、压缩机、流化床、精馏塔）的工艺参数（温度、压力、压差、流量）实时监控。报警管理系统和可燃气体报警系统已部署。设备运维已部分数字化（巡检记录、维修工单）。 |
| **卓越级对标** | ✅ **基本满足。** 设备监控和报警已完善。建议升级为**预测性维护**（PdM）系统，利用APC模型和实时数据对关键设备（如还原炉电极寿命、压缩机轴承磨损、泵的振动趋势）进行剩余寿命预测和主动预警。 |
| **佐证材料** | 设备监控系统界面、报警管理系统界面、设备维修台账 |
| **差异/Gap** | 建议引入预测性维护（PdM）+AI振动分析，将被动维修升级为预测性维护。可参考中控的设备健康管理产品线 |

### S13 生产过程智能管控与在线优化
| 维度 | 内容 |
|------|------|
| **对应场景** | 生产作业-场景10：计划排程与动态调度（部分）+ 场景14：智能在线检测 + 场景11的工序优化 |
| **现有基础** | 
- DCS/APC实现精馏、冷氢化等工序的**实时在线优化**
- EMS能源管理系统实现能耗数据的实时监控和优化调度
- MES系统实现生产全流程的数据采集和监控
- 和利时OCS系统将自控工程标准化，支持一线人员快速维护
- 2026年特变电工互动平台披露：新特能源对多晶硅生产线开展**工艺技术调优及数字化改造**——说明持续在推进在线优化 |
| **卓越级对标** | ✅ **满足。** APC系统本身就是"在线优化"的最佳实践——利用多变量预测控制，在约束条件下实时优化工艺参数。APC波动降低30%+的效果直接证明了在线优化能力。 |
| **佐证材料** | APC优化前后对比数据、EMS能源优化报告、2026年数字化改造项目文件 |
| **差异/Gap** | 无重大差距 |

### S14 过程质量在线检测控制
| 维度 | 内容 |
|------|------|
| **对应场景** | 质量管控-场景14+15+16：智能在线检测/质量追溯/质量优化 |
| **现有基础** | 
- 新特能源设有数字化实验检测中心，具备硅料纯度、杂质含量等关键质量指标的检测能力
- 生产过程质量数据通过MES集中控制、可追溯
- 产品质量（纯度等级）通过APC的卡边控制实现实时优化
- EL测试/红外检测（光伏行业典型质量检测手段）
- 不良品率降低**50%**（2016年试点示范项目数据，需核实最新数据） |
