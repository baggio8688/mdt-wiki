## 为什么你需要这个

> "会写代码还意味着一件事：你有了想法，就能自己动手做出来。"  
> — Paul Graham

2025 年底以来，Claude Code、Cursor 等 Coding Agent 的能力已经发生了质变——可以在相当长的时间里自主完成完整的开发任务。但大多数人还卡在 **Vibe Coding** 阶段：生成一个 Demo 看起来能跑，实际上线就崩。

这个仓库的作者（Alex AN）是非技术背景的 MBA 学生，2025 年秋开始学代码，4 个月后就用 Coding Agent 从零开发 SaaS 应用了。他的核心信念是 **Learn by Doing**——不是先学完再做，而是在做的过程中只学当下需要的东西。
