## 为什么 Coding Agent 用户需要理解这些

有人会问：既然 AI 能帮你写代码，为什么还要理解这些概念？

答案是：**AI 是一个乘数，它放大的是你已有的技能。** 如果你对软件运作一无所知，乘数再大，零乘以任何数还是零。

具体来说，你需要心智模型来做三件事：

1. **准确描述你想要的东西** — 否则你说的和 AI 理解的完全不同
2. **评估 AI 生成的结果** — 没有心智模型，你只能看着代码跑起来就觉得"应该没问题"
3. **在出错时定位问题** — 问题可能出在路由、数据库、还是认证？你需要能判断

## 六章核心内容

### 01：互联网是怎么工作的

理解 HTTP 请求与响应、URL 结构、状态码。

- **关键概念**：客户端-服务器模型、HTTP 方法（GET/POST/PUT/DELETE）、状态码（200/404/500）
- **类比**：你（客户端）向餐厅（服务器）点菜（HTTP 请求），服务员告诉你结果（HTTP 响应）

### 02：数据建模

**最高杠杆的技能**——名词变成表。

- **关键概念**：实体、属性、关系类型（一对多、多对多）、主键/外键
- **类比**：把现实世界中的"用户"、"订单"、"商品"这些名词，变成数据库里一张张表格
- **为什么重要**：数据模型一旦定错，后面改的代价极高。花时间把模型想清楚，能省掉 80% 的返工

### 03：请求的生命周期（RCAV 模式）

URL 如何变成你看到的页面。

- **RCAV**：Route（路由）→ Controller（控制器）→ Action（动作）→ View（视图）
- **关键概念**：URL 路由、中间件、控制器逻辑
- **理解这点**：你就理解了全栈应用的基本骨架

### 04：数据库与 CRUD

增删改查——所有应用的骨架。

- **CRUD**：Create（创建）、Read（读取）、Update（更新）、Delete（删除）
- **关键概念**：关系型数据库、SQL 基础、数据完整性

### 05：API

"一切都是 HTTP 请求"。

- **关键概念**：RESTful API、JSON、第三方 API 集成、API Key
- **类比**：菜单——你不需要知道厨房怎么做菜，只需要看菜单点单

### 06：认证与安全

谁是你，你能做什么。

- **关键概念**：Cookie、Session、JWT Token、OAuth、权限控制
- **核心原则**：永远不要信任用户输入

## 教学理念

本模块的方法论同样适用于 Coding Agent 时代：

**螺旋式学习**：不是线性地从 A 学到 Z，而是每一圈都在构建真实产品，每一圈都只学当下需要的知识。学完第一遍觉得半懂不懂？你会在下一圈回来，带着实践经验重新理解。

**先构建，后解释**：先动手把东西做出来，遇到问题再去理解原理。让 AI 先帮你搭出一个能跑的东西，然后逐步理解它是怎么运作的。

**即时学习**：只在你需要的时候学你需要的东西。遇到数据库问题了就去学数据库，遇到认证报错了就去学认证。
