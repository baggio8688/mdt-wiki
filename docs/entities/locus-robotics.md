# Locus Robotics

## 概述

Locus Robotics 是一家专注于仓库自动化和物流机器人的美国公司，开发自主移动机器人（AMR）解决方案。CEO为 Rick Faulk。

## 关键事实

- **所在领域**：仓储物流自动化、自主移动机器人
- **核心产品**：LocusBots — 自主导航的协作式机器人
- **代表观点**：CEO Rick Faulk 认为"自动化的真正风险是什么都不做，而你的竞争对手在行动"，强调不作为的风险大于尝试自动化失败的风险
- **客户群体**：从大型电商履约中心到中小型仓库
