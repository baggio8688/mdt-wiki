# 美国制造业回流热潮一周年：数据告诉我们什么？

> **原文：** *US manufacturing reshoring boom: What the data says one year after "Liberation Day" tariffs*
> **来源：** IoT Analytics（2026-05-12）
> **原文链接：** https://iot-analytics.com/us-manufacturing-reshoring-boom-what-the-data-says/

## 核心要点

- 2025年4月"解放日"关税后，大量CEO承诺回流美国，但一年后的数据**不支持"回流热潮"的判断**
- 制造业建设支出整体下降21%，主要由电子/半导体行业回落拖累
- 排除电子行业后，建设支出增长5.6%，扣除通胀后仅约2.3%
- 制造业就业在关税后反而下降1%

## 中文精读

### 背景：关税催生的回流承诺

2025年2月，特朗普开始对中国、加拿大、墨西哥加征关税。2025年4月"解放日"宣布对几乎所有国家加征广泛关税。

IoT Analytics当年5月发布的报告发现，大量上市公司CEO因此承诺回流美国以避免关税并受益于本地生产。**2025年Q2，227家上市工业企业宣布了足迹变更：**

- 87家扩大现有美国业务
- 33家将生产从中国转移至美国
- 13家从墨西哥/加拿大迁至美国

典型声明：
> "过去五年，我们在美国制造足迹和能力上投资了近100亿美元。今年我们计划再投资20亿美元增加美国产能。"
> — RTX CEO Chris Calio, 2025年4月

### 数据怎么说？

白宫在2026年4月宣称美国正经历"历史上最大的制造业回流浪潮"，引用ISM制造业PMI达到四年高点52.7为证据。

但IoT Analytics的《工业宏观脉搏——2026年5月》报告**给出了更谨慎的判断**：

> "过去12个月里，数十位制造业CEO公开承诺扩大美国制造产能，这在工业领域引发了极大的乐观情绪。然而一年后，领先指标仍几乎看不到回流驱动的制造业热潮的证据，超出正常周期性工业回升所能解释的范围。"

### 关键数据

#### 制造业建设支出

- **峰值（2024年6月）：** 2390亿美元
- **至2026年3月变化：** **下降21%**
- 下滑主要由计算机/电子/电气（CE&E）行业拖累，**该行业从峰值下降44%**（2022年CHIPS法案推动的半导体建厂高峰后自然回落）
- 排除CE&E后，关税启动后建设支出**增长5.6%**，扣除通胀后约**2.3%**

#### 制造业就业

- 关税后制造业就业**下降1%**，不支持回流热潮的论点

#### 增长与下降的细分行业

| 增长 | 下降 |
|------|------|
| 食品/饮料/烟草 | 计算机/电子/电气（-44%） |
| 化学制品 | 机械 |
| 运输设备 | 木材制品 |
| 其他制造业 | |

### 分析框架

> "一个领先指标（建设支出）显示温和增长而非热潮，滞后指标（就业、进出口）同样不支持回流热潮的论点。"

## 对制造业数字化转型的启示

1. **关税驱动的回流是真实趋势，但规模被夸大了** — CEO们的承诺与实际资本支出之间存在差距
2. **周期性回升 vs. 结构性变化** — 当前数据更像正常工业上行周期，而非历史性的结构重塑
3. **对中国供应链转移的启示** — 低端制造向东南亚（越南被301调查）和墨西哥转移仍在继续，但速度并未急剧加速
4. **制造业数字化转型不受关税周期影响** — 无论生产在哪里，数字化、自动化和AI都是长期趋势
