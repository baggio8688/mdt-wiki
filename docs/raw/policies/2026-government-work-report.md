## 一、2025年工作回顾（数字化相关成就）

- **数字经济核心产业增加值**占GDP比重提高到 **10.5%以上**
- **新质生产力**稳步发展：人工智能、生物医药、机器人、量子科技等研发应用走在世界前列
- 持续推进**制造业数字化转型**和"**人工智能＋**"行动，行业应用加快落地
- **数据要素**潜力加快释放
- 全社会**研发经费投入强度**达到 **2.8%**
- 国产大模型引领全球开源生态

## 二、"十五五"时期主要目标和重大任务

### 核心数字化目标
- **数字经济核心产业增加值**占GDP比重达到 **12.5%**
- GDP增长保持在合理区间，各年度视情提出
- 全社会研发经费投入年均增长 **7%以上**
- 科技自立自强水平大幅提高

### 四大战略任务
1. **推动高质量发展** — 发展新质生产力，构建以先进制造业为骨干的现代化产业体系
2. **做强国内大循环** — 扩大内需，纵深推进全国统一大市场建设
3. **推进共同富裕** — 劳动年龄人口平均受教育年限提高到11.7年
4. **统筹发展和安全** — 粮食综合生产能力1.45万亿斤

### 109项重大工程
- 产业基础能力和竞争力提升、新产业新赛道培育发展
- 前沿科技攻关、创新基础能力提升（28项工程）
- 国家综合立体交通网、新型能源体系等基础设施

## 三、2026年政策取向

- **经济增长目标**: **4.5%—5%**
- **财政政策**: 赤字率4%（赤字5.89万亿），超长期特别国债1.3万亿
- **货币政策**: 适度宽松，灵活运用降准降息

## 四、2026年重点任务（制造业/AI/数字化相关）

### （二）加紧培育壮大新动能

**优化提升传统产业：**
- 安排 **2000亿元** 超长期特别国债支持大规模设备更新
- 实施新一轮**制造业重点产业链高质量发展行动**
- 强化**产业基础再造**和**重大技术装备攻关**
- 打造一批**国家先进制造业集群**
- 推行普惠性"**上云用数赋智**"服务
- **拓展智能制造**，新建设一批**智能工厂**和**智慧供应链**
- 发展**智能建造**，培育现代化建筑产业链

**培育壮大新兴产业和未来产业：**
- 央企国企带头开放应用场景
- 打造集成电路、航空航天、生物医药、低空经济等新兴支柱产业
- 培育未来能源、量子科技、生物制造、**具身智能**、脑机接口、6G等未来产业
- 构建促进专精特新中小企业发展壮大机制

**打造智能经济新形态：**
- 深化拓展"**人工智能＋**"，促进新一代**智能终端**和**智能体**加快推广
- 推动重点行业领域人工智能**商业化规模化应用**
- 培育智能原生新业态新模式
- 支持人工智能**开源社区**建设
- 实施**超大规模智算集群**、**算电协同**等新基建工程
- 加强**全国一体化算力**监测调度，支持公共云发展
- 打造"**5G＋工业互联网**"升级版
- 深化数据资源开发利用，健全数据要素基础制度

### （三）加快高水平科技自立自强
- 加强**原始创新**和**关键核心技术攻关**
- 推动**科技创新和产业创新深度融合**
- 建设北京、上海、粤港澳大湾区**国际科技创新中心**
- 一体推进教育科技人才发展

### （九）绿色转型
- 深入推进**零碳园区和工厂建设**
- 设立国家低碳转型基金
- 培育氢能、绿色燃料等新增长点
