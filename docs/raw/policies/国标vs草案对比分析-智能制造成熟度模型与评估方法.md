## 1. 概述

本次征求意见稿（WD 2024005768、WD 2024005769）是对现行 GB/T 39116-2020《智能制造能力成熟度模型》和 GB/T 39117-2020《智能制造能力成熟度评估方法》的**首次修订**。相比2020版，草案在模型框架、能力域构成、评估流程、评分权重等方面均有**重大调整**。

根据工信部《智能工厂梯度培育要素条件（2025年版）》，**卓越级智能工厂**对应成熟度**三级以上**要求。因此，草案的变化将直接影响新特能源从现有状态升级到卓越级的路径规划。

## 2. 模型结构对比（GB/T 39116）

### 2.1 总体框架变化

| 维度 | GB/T 39116-2020（现行） | WD 2024005768（草案） | 变化说明 |
|------|------------------------|----------------------|----------|
| **模型层次** | 2层：能力要素(4) → 能力域(12) + 子域 | 1层：能力域(5) → 能力子域(25) | **去掉了"能力要素"层**，改用扁平5域结构 |
| **能力要素** | 人员、技术、资源、制造 | 无 | 取消要素分层 |
| **能力域数量** | 12个（分散在4要素下） | 5个 | 重组为组织战略、工厂建设、研发设计、生产作业、业务运营 |
| **能力子域数量** | 约16-17个（2020版中分散定义，未统一编号） | 25个 | 大幅扩充，**细化拆分** |
| **适用范围** | 未明确提及智能工厂 | 明确"适用于企业**智能工厂建设**" | 与梯度培育政策衔接 |
| **术语新增** | — | 知识库、数据模型、数字化模型、模型库 | 反映AI/数字孪生技术发展 |

## 3. 能力域/子域详细对比

### 3.1 组织战略

| 子域 | GB/T 39116-2020 | WD 2024005768 | 差异 |
|------|-----------------|---------------|------|
| 战略规划 | ✅ 有 | ✅ 有 | 草案加强了数字化战略与业务战略的融合要求 |
| 组织管理 | ✅（部分） | ✅ 有 | 草案独立成域，新增数字化组织架构要求 |
| 人才培养 | ✅（人员技能） | ✅ 有 | 从"人员技能"升级为"人才培养"，强调数字技能培训体系 |
| 精益管理 | ❌ | ✅ **新增** | 草案新增，三级起要求精益绩效体系，五级要求AI驱动的精益优化 |

### 3.2 工厂建设（2020版为资源要素下的装备、网络 + 技术要素下的数据、集成、信息安全）

| 子域 | 2020版位置 | 草案位置 | 关键变化 |
|------|-----------|---------|---------|
| 工厂规划 | ❌ 无 | 独立子域（12%权重） | **全新**，三级要求数字化建模/仿真 |
| 装备及产线 | 装备要素→部分要求 | 独立子域（35%权重） | 大幅强化，新增数字孪生（三级+）、联网率等明确指标 |
| 网络 | 资源→网络 | 迁入工厂建设（12%） | 要求提升，五级要求全要素全流程互联互通 |
| 集成 | 技术→集成 | 迁入工厂建设（12%） | 基本延续但要求更具体 |
| 信息安全 | 技术→信息安全 | 迁入工厂建设（12%） | 新增数据安全分级分类要求 |
| 数据 | 技术→数据 | 迁入工厂建设（17%） | 大幅强化，新增数据治理、数据模型、知识库要求 |

> **注**：工厂建设在草案中权重从15%（2020版"资源"）**提升到24%**，成为流程型企业第二重要评估域。

### 3.3 研发设计（2020版为制造要素下的"设计"）

| 子域 | 2020版 | 草案 | 差异 |
|------|--------|------|------|
| 产品创新 | ❌ | ✅ 独立子域（50%权重） | **全新**，三级起要求产品创新平台 |
| 产品设计 | 2020版设计域 | ✅ 独立子域（仅离散型） | 供应链整合设计 |
| 工艺设计 | 2020版设计域 | ✅ 独立子域（50%权重） | 大幅扩充，五级要求工业大模型、自适应决策 |

> **注意**：流程型企业（如新特能源）的研发设计评估域**只有产品创新和工艺设计**两个必选子域，产品设计为可选（表1明确标注）。

### 3.4 生产作业（草案核心域）

草案将生产作业扩充为 **7个能力子域**（2020版仅笼统的"生产"要素），总权重 **42%**（流程型）。

| 子域 | 草案权重 | 新生要求 | 
|------|---------|---------|
| 排产与调度 | 13% | 三级起要求AI排产算法，五级要求产业链协同排产 |
| 作业执行 | 18% | 三级要求产线自动化，四级无人化，五级柔性制造 |
| 质量管理 | 15% | 三级质量数据算法模型，四级全生命周期追溯，五级全供应链追溯 |
| 设备管理 | 15% | 三级故障知识库，四级预测模型，五级自感知/自诊断/自修复 |
| 仓储配送 | 13% | 三级自动化仓储，四级AGV+精准配送，五级动态规划 |
| 安全环保 | 13% | 三级安全风险自动识别，四级全域风险态势感知，五级自感知/自决策 |
| 能碳管理 | 13% | **全新**，三级能源管理信息系统，四级智能调度，五级零碳工厂 |

### 3.5 业务运营（草案新增整合域）

| 子域 | 草案权重 | 来源 |
|------|---------|------|
| 计划 | 20% | **全新**，从2020版"生产"要素中独立 |
| 采购 | 20% | **全新**，从2020版"物流"中独立 |
| 物流 | 20% | 从2020版"物流"迁入，大幅强化 |
| 营销 | 20% | 原"销售"升级，新增客户画像、需求预测 |
| 服务 | 20% | 基本延续，新增大语言模型/数字人 |

## 4. 评估方法对比（GB/T 39117）

### 4.1 评估流程变化

```
GB/T 39117-2020:
  预评估 → 正式评估 → 发布现场评估结果 → 改进提升

WD 2024005769（草案）:
  预评估 → 正式评估 → ★弱项整改 → 改进提升
                       │
                       ├─ 受评估方提交评估弱项整改措施
                       └─ 评估组验证整改可行性
```

**关键变化**：新增"**弱项整改**"环节，正式评估后多了受评估方整改→评估组验证的闭环。这意味着：

- 评估不再是"一次性"打分，而是整改验证后给出最终等级
- 受评估方在现场评估后有机会对发现的弱项进行补救
- 评估组需要验证整改方案的可行性

### 4.2 评估人日要求（草案新增）

草案首次明确了各等级评估的最低人日要求：

| 申请等级 | 预评估（人日） | 正式评估（人日） |
|---------|--------------|----------------|
| 一级 | — | 2人×2天=4 |
| 二级 | 1人×2天=2 | 3人×2天=6 |
| **三级** | **3人×2天=6** | **5人×3天=15** |
| 四级 | 3人×2天=6 | 5人×4天=20 |
| 五级 | 5人×3天=15 | 7人×4天=28 |

**卓越级（三级+）的最低人日门槛：21人日。**

### 4.3 企业内部评估师要求（草案新增）

> **三级及以上**评估，正式评估阶段评估组应至少包含**一名企业内部评估师**。

这意味着新特能源在申请卓越级之前，需要**至少培养一名内部评估师**。

### 4.4 评估权重体系对比

#### 流程型制造企业

| 评估域 | GB/T 39117-2020 | WD 2024005769 | 变化 |
|--------|----------------|--------------|------|
| 人员 → 组织战略 | 6%（人员要素） | **7%**（组织战略） | +1%，含新增精益管理 |
| 技术 → 工厂建设 | 11%（技术要素含数据/集成/安全）+ 15%（资源要素含装备/网络） = 约26% | **24%** | 从分散到集中，权重集中 |
| 设计 → 研发设计 | 包含在制造要素中（未单独列出） | **4%** | 独立成域但权重最低 |
| 制造 → 生产作业 | 制造要素中生产部分（含排产、执行、质量、设备等）约63% | **42%** | ⚠️ **大幅下降21%** |
| 物流+销售+服务 → 业务运营 | 制造要素15% | **23%** | **大幅提升8%**，成为第二重要 |

**权重趋势解读：**

```
                 2020版            草案
               ┌──────┐         ┌──────┐
   生产作业     │ 63%  │         │ 42%  │ ⬇️
   业务运营     │ 15%  │         │ 23%  │ ⬆️⬆️
   工厂建设     │ 15%①│         │ 24%  │ ⬆️⬆️
   研发设计     │  包含 │         │  4%  │ ⬇️
   组织战略     │  6%  │         │  7%  │ ➡️

   ① 2020版"资源"要素（装备15%+网络，不含数据/集成/安全）
```

**核心发现**：
1. **生产作业**权重从63%→42%，不再是一支独大
2. **业务运营**从15%→23%成为第二权重，供应链/采购能力变得关键
3. **工厂建设**从15%→24%显著提升，工厂规划、装备及产线、数据治理成为重点
4. 权重更加均衡，体现从"重制造"到"全链条"的转型思路

#### 草案流程型 vs 离散型权重对比

| 能力域 | 流程型 | 离散型 | 差异分析 |
|--------|-------|-------|---------|
| 组织战略 | 7% | 7% | 一致 |
| 工厂建设 | **24%** | **15%** | 流程型更高，反映流程行业工厂数字化基础要求更高 |
| 研发设计 | **4%** | **11%** | 离散型更高，产品迭代快 |
| 生产作业 | **42%** | **37%** | 流程型更高，但差距缩小 |
| 业务运营 | **23%** | **30%** | 离散型更高，供应链协同要求更突出 |

### 4.5 分数与等级对应关系

草案首次给出明确的分值区间：

| 成熟度等级 | 对应评分区间 | 新特能源目标 |
|-----------|------------|------------|
| 一级 | 0.8 ≤ S < 1.8 | — |
| 二级 | 1.8 ≤ S < 2.8 | — |
| **三级（卓越级门槛）** | **2.8 ≤ S < 3.8** | ✅ |

| 五级 | 4.8 ≤ S ≤ 5 | — |

## 5. 核心差异总结表

### 5.1 模型（GB/T 39116）变化一览

| 对比维度 | GB/T 39116-2020 | WD 2024005768 |
|---------|----------------|---------------|
| 发布/修订状态 | 现行国标 | 第一次修订征求意见稿 |
| 模型结构 | 2层：4要素→能力域 | 1层：5能力域 |
| 能力域数量 | 12个 | 5个（重组） |
| 能力子域数量 | ~17个 | 25个（+8个新增子域） |
| 精益管理 | ❌ | ✅ 新增 |
| 能碳管理 | ❌ | ✅ 新增（含双碳要求） |
| 工厂规划 | ❌ | ✅ 新增（含数字孪生） |
| 产品创新/设计 | ❌ | ✅ 新增 |
| 数据子域 | 基本的数据采集 | 数据治理、数据模型、知识库 |
| 装备要求 | 通用装备管理 | 装备及产线、数字孪生、柔性产线 |
| 安全环保 | 基本安全 | 安全环保（含环保监测、风险态势） |
| 计划/采购 | 包含在生产中 | 独立子域 |

### 5.2 评估方法（GB/T 39117）变化一览

| 对比维度 | GB/T 39117-2020 | WD 2024005769 |
|---------|----------------|---------------|
| 评估流程阶段 | 4阶段 | 5阶段（+弱项整改） |
| 弱项整改 | ❌ | ✅ 新增闭环 |
| 评估人日要求 | ❌ 未明确 | ✅ 明确各等级人日 |
| 内部评估师 | ❌ | ✅ 三级起需内部评估师1名 |
| 评估域/权重 | 按要素分配 | 按能力域分配 |
| 流程型生产作业权重 | ~63% | 42% |
| 流程型业务运营权重 | 15%（物流+销售+服务） | 23%（+计划+采购） |

| 等级分数区间 | ❌ 未明确定义 | ✅ 五级分别定义 |
| 行业成效指标 | ❌ 无 | ✅ 附录A给出参考值 |
| 与企业自评的衔接 | ❌ 未明确 | ✅ 鼓励内部评估师参与 |

### 5.3 对卓越级（三级）的影响

| 事项 | 2020版规则下 | 草案规则下 | 影响 |
|------|------------|-----------|------|
| 三级需覆盖的评估域 | 人员+技术+资源+制造 | 组织战略+工厂建设+研发设计+生产作业+业务运营 | **范围更广**，5域25子域全要覆盖 |
| 三级最低人日 | 未明确 | 21人日（预评估6+正式评估15） | **门槛提高** |
| 内部评估师 | ❌ 不要求 | ✅ 至少1名 | **新增要求** |
| 弱项整改 | ❌ 不适用 | ✅ 正式评估后需整改并通过验证 | **流程变长** |
| 精益管理 | 不考核 | 三级要求建立精益管理体系 | **新增短板** |
| 能碳管理 | 不考核 | 三级要求能源管理系统+碳排放跟踪 | **新增短板** |
| 工厂规划 | 不考核 | 三级要求三维数字化建模 | **新增短板** |
| 业务运营权重 | 15% | 23% | **重要性翻倍** |

## 6. 对新特能源创建卓越级智能工厂的落地建议

> 基于现有 `xinte-smart-factory-scenario-mapping.md`（业务场景映射）和 `xinte-scenario-instance-checklist.md`（场景实例检查表），结合草案要求进行分析。

### 6.1 新特能源现有基础评估

从现有文档分析，新特能源在以下方面已有较好积累：

| 能力域 | 现有覆盖 | 优势 | 短板 |
|-------|---------|------|------|
| **组织战略** | 战略规划、组织管理 | 有数字化转型战略 | ⚠️ 精益管理体系需完善 |
| **工厂建设** | 装备、网络、集成 | 已有系统集成基础 | ⚠️ 工厂规划/数字孪生需新建 |
| **研发设计** | 工艺设计 | 多晶硅工艺积累深厚 | ⚠️ 产品创新、知识库待强化 |
| **生产作业** | 排产调度、质量、设备、安全 | 场景映射中已有大量场景 | ⚠️ 能碳管理系统化不足 |
| **业务运营** | 物流、服务 | 已有基础 | ⚠️ 计划、采购数字化需补齐 |

### 6.2 分域补齐建议

#### ① 组织战略（权重7%）

```
现状：有数字化转型战略和IT组织架构
草案三级要求：精益管理体系 + 关键绩效指标管理
补齐行动：
  □ 建立精益管理体系文件（含精益改善流程、KPI体系）
  □ 培养精益管理内部专家（2-3人）
  □ 将精益KPI与数字化系统对接（实现在线监控）
```

#### ② 工厂建设（权重24% ⬆️ 重点）

```
现状：有DCS、MES、ERP等系统，设备联网已有基础
草案三级要求：数字孪生仿真 → 工厂三维建模
补齐行动：
  □ 完成厂区/车间三维数字化建模（建议用SolidWorks或Unity做3D工厂）
  □ 对产线关键设备做数字孪生仿真模型
  □ 建立数据治理体系（数据标准、数据目录、数据质量管控）
  □ 完善信息安全（数据安全分级分类、等保2.0三级）
  □ 关键工控网络按安全标准改造
```

#### ③ 研发设计（权重4%）

```
现状：多晶硅生产工艺设计经验成熟
草案三级要求：产品创新平台 + 工艺设计数字化
补齐行动：
  □ 建立产品创新管理平台（需求分析→研发项目管理）
  □ 工艺参数数据库建设（积累历史工艺数据形成知识库）
  □ PLM/工艺管理系统与MES/ERP集成
  □ 构建工艺优化模型（如基于历史数据的参数推荐）
```

#### ④ 生产作业（权重42% ⚠️ 核心）

```
现状：场景映射中已有排产、作业执行、质量、设备、安全等场景
草案三级要求较高，需逐子域对齐：

  排产与调度（13%）：
  □ 已具备基础→升级为有限产能排产 + 异常自动预警
  □ 推荐：APS（高级排产系统）建设

  作业执行（18%）：
  □ 关键工序自动化 → 产线级自动化（多工序联动）
  □ 生产过程数据实时采集和追溯

  质量管理（15%）：
  □ 关键工序在线检测 → 质量数据算法模型（预测性质量）
  □ 质量缺陷判定闭环管理

  设备管理（15%）：
  □ 设备台账+点巡检 → 故障知识库 + 故障预测模型
  □ 设备OEE在线统计和管理

  仓储配送（13%）：
  □ 自动化仓储（AGV/立体库） + 物料精准配送
  □ 仓储WMS与MES/ERP集成

  安全环保（13%）：
  □ 安全风险自动识别 + 环保数据在线采集
  □ 应急预案管理 + 高危区域无人巡检

  ⚠️ 能碳管理（13%）（全新）：
  □ 搭建能源管理信息系统（EMS），实现水电气等能耗监控
  □ 高耗能设备节能改造
  □ 碳排放核算方法建立 + 碳足迹跟踪
  □ 建议：已投用的多晶硅还原炉等关键能耗设备重点监控
```

#### ⑤ 业务运营（权重23% ⬆️）

```
现状：部分信息化
草案三级要求大幅提升，需系统性补齐：

  计划（20%）：
  □ 建立产销协同机制
  □ 信息系统自动生成主生产计划+物料需求计划（MRP）
  □ 供应链端到端可视

  采购（20%）：
  □ 供应商全生命周期管理（资质、绩效、分级）
  □ 采购全过程精细管控

  物流（20%）：
  □ 运输计划+调度信息系统化
  □ 物流关键节点跟踪

  营销（20%）：
  □ CRM系统（客户管理、销售线索、订单管理）
  □ 销售与生产/采购/物流的协同

  服务（20%）：
  □ 客户服务平台（在线服务）
  □ 服务流程管理+满意度量化评价
```

### 6.3 弱项整改环节的应对策略

草案新增的"弱项整改"环节直接影响了评估策略：

```
评估前                   评估中                    评估后
┌─────────┐     ┌───────────────┐     ┌──────────────┐
│ 提前自查  │     │ 现场评估发现    │     │ 弱项整改方案   │
│ 模拟评估  │ ──→ │ 识别弱项       │ ──→ │ 评估组验证    │
│ 识别短板  │     │ 与评估组沟通    │     │ 通过→发证    │
└─────────┘     └───────────────┘     └──────────────┘
```

**应对策略**：
1. **评估前**：请内部评估师做一次模拟评估，提前暴露弱项并整改
2. **评估中**：对明确不符合的条款当场记录，准备整改预案
3. **评估后**：15天内提交整改方案，3个月内完成整改并接受验证

### 6.4 与2025版梯度培育要素条件的衔接

工信部《智能工厂梯度培育要素条件（2025年版）》中，**卓越级智能工厂**的要素条件与草案三级要求高度对口：

| 梯度要素 | 对应的草案能力域 | 新特能源关注点 |
|---------|----------------|---------------|
| ① 先进工艺设计 | 研发设计→工艺设计 | 多晶硅还原工艺优化 |
| ② 智能化生产作业 | 生产作业→排产/执行/质量 | APS、MES深度应用 |
| ③ 智能工厂建设 | 工厂建设→装备/网络/数据 | 数字孪生、数据治理 |
| ④ 智造装备应用 | 工厂建设→装备及产线 | 自动化/智能化装备升级 |
| ⑤ 绿色安全发展 | 生产作业→能碳/安全环保 | 碳排放管理、安全管控 |
| ⑥ 组织战略保障 | 组织战略→战略/组织/人才 | 精益管理、人才梯队 |
| ⑦ 供应链协同 | 业务运营→计划/采购/物流 | 产销协同、供应商管理 |

> 两者基本一一对应，**草案的三级要求实际上就是卓越级的评审标准**。

## 7. 行动路线图

### 建议分三阶段推进

```
Phase 1：差距评估（1-2个月）     Phase 2：建设补齐（6-12个月）    Phase 3：评估冲刺（3-6个月）
┌────────────────────┐         ┌────────────────────┐         ┌────────────────────┐
│ □ 对照草案逐条自评     │         │ □ 能碳管理系统上线     │         │ □ 内部评估师培养到位  │
│ □ 找出当前等级（预估） │ ──→ │ □ 精益管理体系建立     │ ──→ │ □ 模拟评估2轮       │
│ □ 识别20+项差距      │         │ □ 工厂三维建模完成     │         │ □ 整改闭环           │
│ □ 制定投资预算       │         │ □ 业务运营数字化补齐   │         │ □ 正式提交评估申请   │
│ □ 培养1-2名内审员    │         │ □ 数据治理体系建成     │         │ □ 通过正式评估       │
└────────────────────┘         └────────────────────┘         └────────────────────┘
```

### 优先级矩阵

| 紧急度 | 影响大（高权重/门槛） | 影响中 | 影响小 |
|-------|-------------------|--------|--------|
| **紧急** | 能碳管理（全新13%）<br>工厂规划/数字孪生（24%权重） | 精益管理体系 | — |
| **常规** | 业务运营系统（23%权重）<br>弱项整改流程设计 | 产品创新平台 | 服务数字化细节 |
| **可滞后** | 零碳工厂（五级要求） | 产业链协同排产 | AR远程维护 |

### 关键里程碑建议

1. **第1个月**：完成草案全条对标自评，发布差距分析报告
2. **第2个月**：启动能碳管理系统选型/建设
3. **第3个月**：完成精益管理体系文件编制
4. **第4个月**：启动工厂三维建模项目
5. **第5个月**：业务运营(计划/采购)系统上线
6. **第6-8个月**：内部试评1-2次，整改闭环
7. **第9-12个月**：正式提交评估申请
