# 工业数据筑基行动：面向AI赋能的高质量行业数据集建设先行先试

> **发文字号：** 工信厅信发函〔2026〕64号
> **发布日期：** 2026-03-11
> **发布机构：** 工业和信息化部办公厅（信息技术发展司）
> **实施周期：** 至2026年12月

---

## 📋 一、总体思路

以推进工业数据开发利用为主线，选取制造业重点行业，依托重点行业企业、平台机构、先进制造业集群、中小企业数字化转型城市试点等主体分类施策，以典型场景需求为牵引，聚焦关键环节关键场景"小切口"开展先行先试，着力突破工业数据"**采**""**集**""**用**"瓶颈。

### 🎯 2026年底目标

| 产出 | 说明 |
|:----|:------|
| 行业数据合作联合体 | 一批 |
| 行业数据可信互联平台 | 重点行业搭建 |
| 行业数据资源 | 汇聚一批 |
| 数据关键技术 | 攻关一批 |
| 工业数据标准 | 研制一批 |
| 高质量行业数据集 | 打造一批（高质量、标准化、可流通） |
| 行业大模型/工业智能体应用 | 赋能一批 |

---

## 🏢 二、四类实施主体

| 类型 | 牵头方 | 主要任务 |
|:----|:------|:--------|
| **① 重点行业企业** | 钢铁、汽车等行业龙头企业 | 企业间及产业链数据开发利用、流通协作机制、行业关键数据技术攻关 |
| **② 平台机构** | 工业互联网平台、大数据中心、制造业数字化转型促进中心 | 跨行业跨领域数据汇聚和共享流通、数据可信互联平台建设 |
| **③ 先进制造业集群** | 国家先进制造业集群 | 数据要素协同供给、数据服务产业生态培育、公共数据授权运营 |
| **④ 中小企业数字化转型城市试点** | 试点城市 | 中小企业数智化升级、工业数据训练基地建设、数据流通交易 |

---

## 📐 三、"1+4+N"体系架构

### 1️⃣ 一个平台
**行业数据可信互联平台**
- 整合工业互联网、大数据中心、算力中心、数据治理平台、数据工程能力平台、行业可信数据空间
- 布局工业数据生产训练基地：仿真环境数据采集、专业化数据标注、极端场景数据合成

### 4️⃣ 四大资源库

| 资源库 | 内容 |
|:-----|:------|
| **行业数据资源库** | 操作手册、安全规范、学术论文、技术专利等知识数据 + 设备信息、生产过程、运行环境等实时数据 + 生产工单、产品信息、供应链协同等业务数据 |
| **数据技术攻关库** | 多模态数据治理、多源异构数据加工、智能标注、数据合成等关键技术，编制工业数据关键技术图谱 |
| **工业数据标准库** | 工业数据采集汇聚、高质量数据集建设、数据开发利用等关键急需标准 |
| **高质量行业数据集库** | 已建/规划数据集目录，典型案例征集，数据集建设指引 |

### N️⃣ N个应用场景
- **研发设计、中试验证、生产制造、经营管理、产业协同**等关键环节
- 行业大模型应用、工业智能体研发
- 公共数据授权运营、工业数据确权、价值评估与收益分配、数据流通交易

## 📝 六、政策要点分析

1. **政策定位**：本文件是"工业数据筑基行动"的**启动/纲领文件**，定义了"1+4+N"完整体系架构
2. **与"模数共振"的区别**："模数共振"侧重模型与数据的协同（含行业模型+数据集），本文件侧重**工业数据基础设施**（采集、流通、标准化）
3. **与"AI+制造"实施意见的关系**：本文件落实了实施意见中"开展'模数共振'行动"和"夯实企业数据治理基础"的要求，聚焦数据侧
4. **对新特能源的价值**：
   - 先进制造业集群类主体可申请成为联合体
   - "1+4+N"体系为数据治理提供标准化框架
   - 行业数据资源库+高质量数据集建设直接对标智能工厂数据域
