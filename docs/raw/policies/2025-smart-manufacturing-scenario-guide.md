# 智能制造典型场景参考指引（2025年版）

> 原始文件：[PDF](assets/03_智能制造典型场景参考指引（2025年版）.pdf)
> 关联通知文号：工信厅通装函〔2025〕155号

## 概述

本指引定义了智能工厂建设的**8个环节、40个典型场景**，覆盖产品全生命周期、生产全过程和供应链全环节，指导企业识别应用场景、规划建设路径。

## 一、工厂建设

| # | 场景 | 说明 |
|---|------|------|
| 1 | **产线级/车间级/工厂级数字化规划与设计** | 人员、物料、设备、能源、工艺等系统级规划与仿真 |
| 2 | **数字基础设施建设** | 工业网络、工业计算存储、工业数据采集等基础设施建设 |
| 3 | **数字孪生工厂** | 工厂数字孪生构建、虚实融合与互操作 |
| 4 | **数据治理** | 数据资产管理、数据质量管理、数据流通利用 |
| 5 | **工业技术软件化** | 工艺知识沉淀、工业软件和工业APP应用 |

## 二、研发设计

| # | 场景 | 说明 |
|---|------|------|
| 6 | **产品数字化设计** | 基于模型的产品三维设计，产品设计与工艺协同 |
| 7 | **虚拟仿真与验证** | 产品结构、性能、可制造性仿真验证 |
| 8 | **协同研发设计** | 跨部门、跨企业协同研发平台 |
| 9 | **知识驱动研发** | AI赋能的创新设计、知识图谱辅助研发 |

## 三、生产作业

| # | 场景 | 说明 |
|---|------|------|
| 10 | **计划排程与动态调度** | 自动排产、实时重排、多目标优化 |
| 11 | **智能生产作业** | 柔性产线、人机协同、自适应工序 |
| 12 | **先进过程控制** | APC、模型预测控制、AI工艺优化 |
| 13 | **智能仓储与物料配送** | AGV/AMR自动配送、WMS/WCS集成 |

| 15 | **质量追溯与分析改进** | 产品全生命周期质量追溯 |
| 16 | **质量优化与持续改进** | SPC、六西格玛、AI质量预测控制 |

## 场景与要素条件的映射关系

《要素条件》与《场景指引》按一一对应关系设计：

| 要素条件环节 | 场景指引环节 |
|-------------|------------|
| **工厂建设** | 工厂建设 + 信息基础设施（场景1-5, 34-37） |
| **研发设计** | 产品设计 + 工艺设计（场景6-9） |
| **生产作业** | 生产作业 + 质量管控 + 设备管理（场景10-18） |
| **生产管理** | 计划调度 + 仓储物流 + 安全管控 + 能碳管理 + 环保管理（场景10-14, 19-27） |
| **运营管理** | 营销与售后 + 供应链管理（场景28-33） |

> 注：计划排产（场景10）横跨"生产作业"和"生产管理"两个要素环节
