# 两部门关于联合实施2026年"模数共振"行动的通知

> **发布机构：** 工业和信息化部办公厅、国家数据局综合司
> **政策依据：** 《国务院关于深入实施"人工智能+"行动的意见》《"人工智能+制造"专项行动实施意见》

---

## 📋 一、背景与依据

为深入贯彻党中央、国务院关于人工智能发展的决策部署，落实《国务院关于深入实施"人工智能+"行动的意见》《"人工智能+制造"专项行动实施意见》要求，推动人工智能模型与数据资源协同互促、同频共振，工业和信息化部、国家数据局联合开展2026年"模数共振"行动。

> **"模数共振"概念来源：** 《"人工智能+制造"专项行动实施意见》第三条第（三）款首次提出开展"模数共振"行动，此处为本实施意见的具体落实文件。

## 🎯 二、覆盖行业范围

重点面向以下 **20+行业/领域**：

| 类型 | 具体行业 |
|:----|:--------|
| **原材料** | 钢铁、石化化工、有色金属、建材 |
| **装备制造** | 工业母机、汽车、医疗装备、电力装备、船舶、航空航天 |
| **消费品** | 家居、医药、生物制造、历史经典 |
| **电子信息** | 电子元器件、消费电子、新型显示、软件、信息通信、网络安全 |

## 📂 三、七大重点任务

### 任务1：构建行业通识数据集，打造行业模型

- 各省级地区至少选择 **3个行业**，每家央企至少选择 **1个行业**
- 每行业梳理不少于 **5个** 高质量数据集，形成《重点行业通识高质量数据集清单》
- 研发能够掌握行业知识规律、满足行业应用需求的行业模型

### 任务2：梳理高价值场景，构建行业专识数据集，打造特色智能体

- 每行业凝练不少于 **30个** 高价值场景，形成《重点行业AI高价值场景档案》
- 每个场景构建不少于 **1个** 行业专识高质量数据集
- 打造专用模型或特色智能体

### 任务3：建立健全评测数据集，完善模型评测机制

- 构建特色化、定制化的评测数据集
- 构建面向行业应用的模型能力评测体系
- 形成"评测诊断→数据集定向优化→模型能力提升"的良性循环

### 任务4：创建"模数共振"空间，探索协同机制

- 每省级地区打造不少于 **3个**，每央企不少于 **1个**
- 承载跨主体数据汇聚和模型训练的软硬件基础设施
- 实现跨主体数据可信贯通、模型协同训练与安全合规应用
- 鼓励与国家数据基础设施互联互通

### 任务5：打造"模数共振"创新联合体，构建全栈方案

- 每行业打造不少于 **1个** 创新联合体
- 引导算力企业、模型企业、数据企业和应用开发企业组建
- 与"模数共振"空间协作联动
- 打造AI赋能行业"样板间"

### 任务6：完善生态配套，加强关键要素保障

- 组织"深度行"活动、建设实训基地
- 系统培养多元复合型人才（行业+数据+模型）
- "揭榜挂帅"机制强化技术创新
- "标准行"活动加大标准宣贯

### 任务7：确定"重点城市"打造标杆

- 有先导区/中试基地的省级地区：最多 **3个城市**
- 其他省级地区：最多 **2个城市**
- 重点城市在全市范围内推动"模数共振"落地

## 📝 政策要点分析

1. **政策层级**：本文件是"人工智能+制造"专项行动实施意见的**首个具体落实文件**，聚焦"模数共振"这一细项任务
2. **行业覆盖**：20+行业覆盖制造业全口径，与智能工厂梯度培育的行业范围高度重合
3. **申报时间紧迫**：2026年5月30日前需报送实施方案，8月中评估，11月底总结
4. **数据安全要求**：各任务中涉及数据处理、对外提供的环节需说明安全保护措施
5. **与智能工厂梯度培育的联动**：可同步利用智能工厂申报材料中的场景数据，构建行业通识/专识数据集
6. **模板体系完整**：7份成果模板形成标准化输出框架，便于成果汇总和推广
